## 数据窗口与来源

默认使用最近完整交易日 `T`：

- 涨停基因窗口：`T` 向前约6个自然月，按有效交易日聚合。
- 形态窗口：`T` 向前约3个自然月，通常约60至65个交易日。
- 近期活跃度：`T` 向前30个自然日。

参考源：

- 涨停池：`https://api.momaapi.com/hslt/ztgc/{YYYY-MM-DD}/{TOKEN}`
- 炸板池：`https://api.momaapi.com/hslt/zbgc/{YYYY-MM-DD}/{TOKEN}`
- 文档：`https://momaapi.com/docs-shares.html`
- 腾讯前复权日线：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={symbol},day,{start},{end},320,qfq`
- 上交所交易规则：`https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml`
- 深交所主板交易机制：`https://investor.szse.cn/institute/rules/t20230629_601434.html`

公开接口可能限速、回退或变更字段。保留缓存和来源ID；任何非交易日返回的榜单都必须丢弃。

## 事件字段标准化

封板与炸板事件统一为：

- `date`, `code`, `name`, `industry`
- `first_time_s`, `last_time_s`
- `breaks`, `streak`, `turnover`
- `amount`, `float_cap`, `pct`
- `result`: `sealed` 或 `failed`

把 `HH:MM:SS`、`HHMMSS` 和数值时间统一为午夜后的秒数。缺失时间不计入快板率分母，但必须记录缺失数量。

封板成功率：

```text
sealed_count / (sealed_count + failed_count)
```

快板率：

```text
first_limit_time <= 10:00 的封板次数 / 首次封板时间有效的封板次数
```

## 涨停基因评分

原始得分：

```text
100 × [
  35% × MIN(1, 近6月封板次数 / 12)
  + 25% × 封板成功率
  + 20% × 快板率
  + 10% × 行业联动率
  + 10% × MIN(1, 近30日封板次数 / 3)
]
```

样本可靠性收缩：

```text
reliability = 0.75 + 0.25 × MIN(1, SQRT(触板次数 / 6))
gene_score = raw_score × reliability
```

收缩用于防止3次触板且全部成功的股票仅凭小样本压过长期反复验证的股票。

## 底部放量评分

### 1. 区间位置

```text
position = (最新收盘 - 3月最低价) / (3月最高价 - 3月最低价)
bottom_score = 100 × CLAMP((0.55 - position) / 0.55, 0, 1)
```

### 2. 放量强度

```text
volume_ratio = 最近5日均量 / 此前20日均量
volume_score = 100 × CLAMP((volume_ratio - 1.0) / 1.2, 0, 1)
```

### 3. 持续性

计算近10日中成交量达到基准均量1.30倍的天数：

```text
persist_score = 100 × CLAMP(active_days / 4, 0, 1)
```

### 4. 趋势修复

- `MA5 >= MA10`：35分。
- `最新收盘 >= MA20`：35分。
- `MA20` 高于此前20日均值：30分。

### 5. 汇总

```text
shape_score =
  38% × bottom_score
  + 30% × volume_score
  + 17% × persist_score
  + 15% × trend_score
  - extension_penalty
```

当区间位置高于55%或近20日涨幅高于25%时扣分，防止把已经脱离底部的加速段纳入。

形态状态：

- 强确认：位置 `<=40%`、量比 `>=1.40`、近10日放量天数 `>=2`、收盘 `>=MA20`。
- 确认：位置 `<=50%`、量比 `>=1.20`、近10日放量天数 `>=2`，且 `MA5>=MA10` 或收盘 `>=MA20`。
- 观察：位置 `<=55%` 且量比 `>=1.05`。
- 不满足：其他。

## 行业启动与联动

行业热日默认定义为同一交易日、同一行业至少3只股票封板。

```text
行业联动率 = 个股封板事件中行业热日次数 / 个股封板次数
```

若用户明确要求识别“当前行业启动周期”，再计算行业最近5个交易日封板数相对此前20日均值的加速比，并将最近5日加速、热日出现和行业覆盖股票数单独展示。不要把行业加速比偷偷混入默认基因分。

## 交叉验证

对每个封板事件日，用独立前复权日线计算：

```text
close_return = close[t] / close[t-1] - 1
```

普通主板 `close_return >= 9.3%` 视为事件一致。第一个缺少前收盘的样本不进入分母。

```text
match_rate = matched_events / comparable_events
```

精筛组默认要求 `match_rate >=90%`。低于门槛时先检查除权、证券更名、ST状态变化、新股无涨跌幅期和数据源错位。

## 默认筛选门槛

同时满足：

- 封板次数 `>=5`
- 基因分 `>=55`
- 形态分 `>=50`
- 封板率 `>=65%`
- 形态为确认或强确认
- 日线一致率 `>=90%`

综合分：

```text
58% × gene_score + 42% × shape_score
```

评级建议：

- A：综合分 `>=68`
- B：综合分 `>=60`
- C：其余通过硬门槛者

## 输出字段

精筛表至少包含：代码、名称、行业、评级、封板次数、炸板次数、封板率、快板次数、快板率、首封中位时间、行业联动率、最大连板、近30日封板、最近封板日、截止收盘、区间位置、距低点、量比、持续放量天数、MA20斜率、20日涨幅、形态状态、形态分、基因分、综合分、日线一致率、风险提示、来源ID。

## 异常与风险处理

- 非交易日接口可能返回最近交易日池：用有效日线交易日集合过滤。
- 当前名称不含ST不代表窗口内从未处于风险警示状态：日线不一致时核对历史状态。
- 新股前5日、重新上市或退市整理首日可能无价格限制：排除或单列。
- 量比 `>3`：提示一次性脉冲或过热，不自动删除。
- 近20日涨幅 `>20%`：提示已扩张。
- 行业联动率 `<40%`：提示孤立事件风险。
- 近30日无封板：提示基因近期未触发。
- 未纳入公告、减持、监管、基本面和封单衰减：在最终报告中明确。
